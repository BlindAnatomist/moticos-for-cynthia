This source is a separately selected 200-piece matching build. No workflow deploys the game. The accepted 160 runtime/art files and lower build modes remain unchanged.

The previous original-art journeys are not claimed as fresh 200 browser passes. Their source and all four lower builds are checked against the exact accepted hashes, in addition to all original unit suites and targeted Garden browser checks.

The run requires 24 distinct actual new PNG exports per profile, 72 total, at 1536×1120. Each new postcard also gets actual compact art/title and action-view evidence at 320×568, 390×664, 430×752: 144 viewport images per profile. ## Fail-closed execution

Only the explicitly approved push to `verify/current-200-20261007` in `BlindAnatomist/moticos-for-cynthia`, run attempt 1, is admitted. This is configuration, not permission to publish or execute it. The default/user-requested confirmation policy still applies.

The accepted V8 infrastructure is reused: one sole-build preflight, current-source/art manifests, exact read-only case collection, one worker, zero retries, fail-fast, exact profile invocation,15–16-minute browser budgets, 26-minute profile jobs and a 4-minute evidence reserve. Preflight has a 10-minute job cap. Maximum configured allocation is 88 runner-minutes across the four jobs; this is not a price quote. No rerun is automatic. The new matrix uses fail-fast:true with max-parallel:1: after a failed profile completes its always-run evidence steps, queued profiles are canceled. This is the deliberate bounded-cost deviation from V8’s independent-profile continuation. Canceled profiles remain unrun, never accepted.

Lossless SHA256 object deduplication and 24 MiB multipart uploads retain every raw evidence byte. Caps remain 96 MiB preflight, 120 MiB Chromium, 240 MiB WebKit iPhone 13 and 264 MiB WebKit large; each browser also has an 8 MiB diagnostic salvage cap. Combined cap 744 MiB plus four identity receipts (at most 32 KiB each). Exceeding a cap fails the run; diagnostic-only evidence cannot substitute for complete evidence.

The workflow has contents:read only and no deploy step. It does not alter budgets, allow paid overages, modify Main, or publish a Site. Source/artifacts need their separately authorized public-repository destination; private recovery material, art masters, credentials, conversation context and repository history are excluded from the source projection.
