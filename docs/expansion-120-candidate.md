# Private 120-piece content candidate

The accepted eighty-piece source is cf172905dc3fec335d4117e86bb9847149b01122. This isolated candidate adds forty individually reviewed canonical images, eight five-stage families and four ten-piece envelopes. It does not alter the accepted eighty artworks, engine, session, storage keys or reducer.

New envelopes are Small Talk (Hand Signals and Face Value), Hello Again (Line Again and Hat Trick), Off Beat (Fine Teeth and Cut Time), and Return Mail (Return Post and Shell Mail). Only identical canonical pictures at the same nonfinal tier merge. Every family still uses 15 merges and six pair draws to reach its fifth tier. The 5×5 board and separately opened postcards are unchanged.

Normal builds remain the original forty-piece variant. `build:batch` retains the accepted eighty-piece routing. `build:expansion` selects the private 120-piece registry and source-bound artwork. The flag is a build selector, not authentication or publication permission. Old envelopes delegate to the exact prior catalog/engine objects, and each new envelope has a new isolated save key.

Art review covered all forty full-size images, 50px and 35px light/dark views, actual compact board-size simulations, paired-envelope comparisons and finale variety against the prior collection. Two failed halo versions of the hat finale and an unrelated comb picture-loop were rejected and preserved privately; only the corrected, independently accepted hashes appear in the source receipt. The shell finale was deliberately authored as a solid asymmetrical crest to vary the open-space progression pattern.

The added lossless WebP runtime payload is 13,172,816 bytes, with every image 768×768. Masters and rejected generation attempts are retained in private recovery, not in the candidate source. This preserves detailed print texture but is not a completed mobile/network/memory performance claim. Browser verification must measure loading and decode behavior on the actual new envelopes.

The separate combined candidate applies the independently reviewed lossless-storage overlay. The content-only candidate has no save-format migration. The combined candidate preserves all 100 retained Undo states and uses a versioned storage wrapper; a rollback must retain that decoder to resume migrated saves. See its save-capacity documentation for the exact transport and limits.

No new GitHub Action, remote branch, public upload, merge, Site push or deployment was performed for this expansion. Runtime browser and real postcard export checks remain a separate, approval-gated stage. The private candidate is a 120-piece milestone toward the requested 300-piece initial collection, not a claim that the larger game or AAA-level experience is finished. Cynthia is not needed for engineering QA.
