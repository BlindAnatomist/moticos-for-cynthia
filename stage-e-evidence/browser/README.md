# Focused direct-drag interaction evidence

This suite adds eight focused cases in each of two browser profiles. It does not rerun, replace, or relabel the previously accepted 22-case campaign/artwork matrix. The prior acceptance is an exact source-bound baseline; these sixteen instances cover the interaction delta and immediate tap, mouse, keyboard, save, reload and Undo regressions.

## Inputs and limits

- Chromium continuous touch uses a Playwright CDP session and `Input.dispatchTouchEvent` (start, multiple moves, end/cancel, and two-contact sequences). Captured browser events assert `isTrusted` and touch pointer identity. This is real Chromium input dispatch in an emulated touch surface, **not physical-iPhone testing**.
- WebKit has native Playwright taps, mouse dragging and keyboard actions. Its continuous touch scenarios are **synthetic handler checks**: dispatched PointerEvents with a narrowly scoped pointer-capture shim, removed at gesture end. They test application handlers, not WebKit's native touch arbitration, scrolling or hardware capture. Raw proof labels every such step. Native WebKit gap/empty swipe, second-finger arbitration and continuous direct-touch dragging remain unverified by this public harness.
- Explicit synthetic detail=1 click checks supplement real event logs for compatibility-click suppression. They are never claimed as browser-generated clicks.
- Releasing Chromium capture uses the real DOM capture API for an existing trusted pointer; cancellation/drop afterward uses the trusted touch input path. Escape uses a native keyboard event.
- The fixture is `createCareer` from the unchanged game engine. Larger-text fixtures are generated by its normal reducer. Expected moves, merges, Undo and external-writer changes use the same reducer, including exact tile IDs, target IDs and revision checks. No desired campaign outcome or inventory is assigned directly.

## Cases

E01: Occupied-to-empty move, matching merge, live ghost/target feedback, exactly one save and revision, reload and Undo.

E02: Unmatched destination, self, gap and outside drops; no save or revision.

E03: Less-than-seven-pixel motion remains a tap; drag compatibility click is suppressed; a fresh native tap works and can complete the next move.

E04: Pointer cancellation, capture loss, another finger and Escape abandon the drag without a durable write.

E05: A real separate-tab session changes the revision or moves the source during a held drag. Only that external command writes; the stale drag never commits. Both pages' write acknowledgements are drained.

E06: Narrow larger-text board. Chromium trusted swipes from empty cells and gaps actually move horizontal scroll. WebKit native accessible scroll controls are covered instead of claiming a native swipe. Edge reveal is measured per frame, remains bounded by the rail, stops outside it, and cancellation saves nothing. Whole-page horizontal overflow is checked. A second drag must actually drop into an empty cell revealed at nonzero scrollLeft, and persist exactly the expected move once.

E07: Native mouse HTML drag move/merge and Undo/reload remain durable.

E08: Native keyboard focus, Enter/Space selection and arrow movement complete a merge and move, with one durable write each, and survive reload.

## Evidence

Each proof stores exact source/build/probe identity, test ID, raw input event rows (`isTrusted`, pointer type, coordinates and target), acknowledged durable writes including exact bytes, semantic step boundaries, measurements, and screenshot hashes/dimensions. The runner adds commit identity, complete Playwright step journals, cleanup and resource evidence. Five successful viewport screenshots are fixed in scope: four Chromium (drag feedback, move, merge, larger-text reveal), one WebKit keyboard result. There is at most one explicit failure screenshot across the serial run. No video or trace is recorded.

Browser acceptance requires the pinned authorized Actions pipeline. A local isolated smoke was attempted with installed Chromium, but browser startup was denied by the local Unix-socket sandbox before any case input. It establishes no browser pass. Production core and probe builds and portable Node contracts can still be checked locally.
